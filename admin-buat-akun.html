Pembuatan Akun Perawat / Bidan Massal

Admin dapat membuat akun login untuk seluruh perawat dan bidan sekaligus menggunakan file Excel/CSV berisi data kepegawaian.
Akun akan dibuat dengan email: NIP@kredensial.rsdsoedarso.id dan password awal otomatis.

1

Siapkan File CSV / Excel

Ekspor data kepegawaian dari SIMRS / SIMPEG dalam format CSV dengan kolom yang ditentukan.

2

Unggah atau Tempel Data

Seret file CSV ke area unggah, atau tempel data langsung dari Excel ke kolom teks di bawah.

3

Verifikasi & Buat Akun

Pratinjau data sebelum diproses. Klik "Buat Semua Akun" – sistem akan buat akun Firebase otomatis.

4

Notifikasi ke Perawat

Sistem menghasilkan daftar akun + password awal untuk didistribusikan via WhatsApp / email instansi.
